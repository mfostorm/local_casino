# Михрюказино

Приватный игровой вечер для компании: телефоны игроков, один общий стол и отдельный экран телевизора. Только виртуальные фишки.

## Запуск

Требуется **Node.js 24+** (SQLite встроен в Node), npm. Дополнительный сервер БД не нужен.

```sh
npm ci
npm run dev
```

Сервер слушает все сетевые интерфейсы на порту **3000**. Для production:

```sh
npm ci
npm run build
npm start
```

Для публичного HTTPS добавлен [Caddyfile](Caddyfile). Настройка nip.io,
автоматического сертификата и запуск на Windows/VPS описаны в
[инструкции HTTPS](docs/https.md).

Переменные окружения:

| Переменная | По умолчанию         | Назначение                                      |
| ---------- | -------------------- | ----------------------------------------------- |
| `PORT`     | `3000`               | HTTP и Socket.IO на одном порту                 |
| `DB_PATH`  | `data/casino.sqlite` | Путь к постоянной SQLite БД                     |
| `NODE_ENV` | development          | `production` включает раздачу собранного `dist` |

В разработке Vite встроен в Node-сервер: отдельный порт и ручной proxy не нужны. npm использует локальный игнорируемый `.npm-cache`, чтобы установка работала в облачной среде без записи в домашний каталог.

## Как провести вечер

1. Откройте приложение, введите имя ведущего и название вечера, нажмите «Открыть своё казино».
2. До первого раунда стартовый баланс можно изменить: он обновится у всех уже подключённых игроков. После первого раунда стартовый баланс фиксируется. В пульте ведущего настройте баланс, ставки, таймеры и лимит возвращений. Стартовые значения: 10 000 фишек, ставки от 10, максимум 1 000 за раунд, три возвращения.
3. Откройте «Пригласить друзей». Друзья сканируют QR-код или вводят шестизначный код. До 10 участников, включая ведущего.
4. Выберите игру в меню и откройте ставки. Закройте их вручную или дождитесь таймера.
5. После раунда можно сменить игру, повторить раунд или включить автоматическое продолжение через 8 секунд. Пауза предотвращает следующий автоматический раунд; уже принятые ставки доигрываются.
6. При нулевом балансе и отсутствии незавершённых ставок игрок запрашивает возвращение. Ведущий подтверждает выдачу полного стартового баланса. Если остаток меньше минимальной ставки, игрок может добровольно сдать его с отдельным подтверждением и запросить возвращение. Сдача записывается в историю. Внешние шуточные условия приложение не отслеживает.
7. Завершите вечер между раундами. Победитель определяется **конечным балансом**. Пополнения не вычитаются, равные балансы делят место.

### Телефоны и телевизор

Все устройства должны открывать **один адрес одного сервера**. В домашней сети это адрес компьютера с сервером, доступный по Wi-Fi. Для удалённых друзей нужен опубликованный сервер с постоянным диском и HTTPS. Не используйте loopback-адрес в QR-коде для других устройств: откройте приложение по его доступному сетевому адресу до копирования приглашения.

Ссылка зрителя доступна ведущему в приглашениях. Откройте её в браузере ТВ или на компьютере, подключённом по HDMI. Она даёт только чтение; скрытая карта дилера и будущие результаты не отправляются зрителю. Ссылки с токенами считаются ключами доступа: передавайте их только нужному человеку.

Сессии игроков сохраняются на устройстве. Экран зрителя использует сессию вкладки и не заменяет сессию ведущего в другом окне. Если игрок потерял доступ, ведущий создаёт личную ссылку восстановления в пульте: прежняя сессия отзывается.

## Игры и выплаты

- **Рулетка:** европейское колесо 0–36, стандартные ставки, включая составные. Прибыль 35:1 на число, 17:1 на сплит, 11:1 на стрит, 8:1 на угол, 5:1 на линию, 2:1 на дюжину/колонку, 1:1 на равные ставки. Одно зеро; без La Partage/En Prison.
- **Блэкджек:** 6 колод, S17, выплата 3:2, проверка блэкджека дилера, удвоение любых первых двух карт и после разделения, до четырёх рук. Разделение одинаковых рангов; тузы — одна дополнительная карта, без повторного разделения. Нет страховки и surrender. По таймеру — «Хватит» на текущей руке.
- **Бакара:** стандартная Punto Banco, 8 колод и таблица добора. Player 1:1, Banker 0,95:1, Tie 8:1. При ничьей основные ставки возвращаются.
- **Кости:** два независимых кубика. Меньше/больше 7 — ×2,4; ровно 7 и дубль — ×6. Конкретная сумма — ×36 / число соответствующих комбинаций. Выплаты без преимущества казино.
- **Утки:** четыре равновероятных победителя, одна выбранная утка на игрока. Выплата ×4 без комиссии. Сервер выбирает победителя, 18-секундная синхронная анимация показывает гонку.

Коэффициенты × включают возврат ставки. В классических трёх играх сохранены стандартные выплаты казино. Башмаки сохраняются между раздачами; перед следующей раздачей при остатке менее 104 карт происходит перемешивание. Если башмак всё же исчерпан в необычно большой раздаче, ставки безопасно возвращаются.

## Хранение и безопасность игрового состояния

- Сервер принимает решения, использует `crypto.randomInt` и Fisher–Yates. Клиент не определяет исход или выплаты.
- Балансы — целое число сотых долей фишки. Ставки и выдачи кратны 10 фишкам, что позволяет точно учитывать все текущие коэффициенты.
- SQLite хранит согласованный снимок комнаты одной атомарной записью: баланс, ставки, действия, башмаки, история и сессии. Один Node-процесс владеет БД; несколько одновременно пишущих экземпляров приложения не поддерживаются.
- Идентификаторы запросов предотвращают повторный расчёт при дублировании сообщения. Идентификатор раунда защищает от устаревших действий.
- После перезапуска незавершённые раунды отменяются, все незавершённые ставки возвращаются (включая split/double), стол ставится на паузу. Завершённые выплаты сохраняются.
- Токены сессий проверяются по SHA-256; клиент получает только допустимую для роли проекцию. Результаты до раскрытия, башмаки и чужие токены не передаются.
- Отдельных аккаунтов и облачного восстановления ведущего нет. Сохраните личную ссылку ведущего; потеря всех его сессий требует доступа к серверу.

Храните `data` на постоянном диске. Для резервного копирования используйте SQLite backup API или остановите приложение перед копированием БД вместе с её WAL-файлами. Не коммитьте данные комнат.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Модульные и интеграционные тесты проверяют математику, все 36 комбинаций кубиков, все типы ставок рулетки, добор бакары, блэкджек, права ролей, повторные входы и восстановление после перезапуска.

Playwright запускает отдельный production-сервер на порту 3100 с отдельной временной БД и независимые браузерные сессии ведущего, двух игроков и зрителя. Проверяет пять игр, синхронизацию, мобильный экран и переподключение. Перед ним нужна сборка.

По умолчанию используется `/usr/bin/chromium`. Для другого установленного Chromium задайте `CHROMIUM_PATH`. При необходимости установите браузер штатным способом вашей ОС. Результаты и скриншоты — в игнорируемом `test-results/`.

## Структура

- `shared/model.ts` — публичные типы, варианты ставок и форматирование.
- `server/games.ts` — игровая математика и работа с колодами.
- `server/store.ts` — комнаты, переходы фаз, баланс, авторизация и постоянное состояние.
- `server/index.ts` — HTTP, Socket.IO, запуск и раздача интерфейса.
- `src/main.tsx`, `src/style.css` — адаптивные экраны игроков, ведущего и ТВ.
- `tests/` — математические, интеграционные и браузерные проверки.

Интерфейс полностью на русском. Шрифты системные, графика локальная SVG/CSS, внешние CDN и платные API не используются.
